# Instructions pour Claude Code

`AGENTS.md` est la source de vérité commune de ce dépôt.

Avant toute analyse, modification, revue, commande ou création d'issue :

1. lire intégralement `AGENTS.md` à la racine ;
2. appliquer toutes ses règles au travail demandé ;
3. lire ensuite les éventuelles instructions plus spécifiques au dossier ou à la
   tâche ;
4. signaler toute contradiction avant une action irréversible ou structurante.

Ne pas recopier les règles communes dans ce fichier. Toute évolution durable des
consignes partagées doit être faite dans `AGENTS.md` afin d'éviter deux versions
divergentes.
